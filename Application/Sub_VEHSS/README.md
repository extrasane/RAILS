# Sub_VEHSS: Subgroup RAILS against the CDC VEHSS benchmarks

> **Status: preliminary, please read before using or citing any VEHSS result.** The AoU-vs-PUMS-vs-VEHSS definition discrepancies found here are a recent and still immature discovery. The region map was just aligned with the Census definition (below), but other definitions are known to differ and have **not** been harmonized or re-run: age group (the VEHSS bands 40-64 / 65-84 / 85+ against the five age groups of the Global pipeline, and AoU age is rounded rather than floored in stage 2), multiracial coding, PUMS income (no inflation adjustment) and group-quarters handling. Outputs made before and after any of these changes are not comparable. Treat the VEHSS comparisons as work in progress; more changes are likely.

Eye-disease applications of Subgroup RAILS, split off from [`../Subgroup RAILS`](../Subgroup%20RAILS/README.md) (the original sex / region pipeline, steps 09-10). Each study builds the AoU cohort aged 40+ from the CDR, defines the phenotype, runs Global RAILS and region-Subgroup RAILS on 40+ cell tables, and compares them with the CDC **V**ision and **E**ye **H**ealth **S**urveillance **S**ystem state estimates.

> **Run inside the AoU Researcher Workbench** (except `VEHSS_data*.R`, which download from the CDC portal and need internet). Copy `Sub_AoU_Fun.R` (from `../Subgroup RAILS/`) and `AoU_Fun.R` (from `../Global RAILS/RAILS Procedure/`) into the working directory: the scripts `source("Sub_AoU_Fun.R")`. `VEHSS_<AMD|GLAUCOMA|CATARACT>_*.csv` (benchmark tables) are expected next to the scripts or in `../data/`.

> **Region definition.** Every script here uses the **official Census regions** (identical to the PUMS `REGION` variable and to steps 02 / 04 / 09): Delaware, Maryland, DC and Oklahoma are in the South. The same state-to-region map is applied to the AoU cohort, the by-state PUMS records and the VEHSS state benchmark. Results from before this change used a different map (DE and MD in the Northeast, DC dropped) and are not comparable.

Downstream: the Transport RAILS scripts (`../Transport RAILS/T01`) read the stage outputs `vehss_*_aou_40plus.csv` written by these scripts.

## Files

| File | Description |
|---|---|
| `VEHSS_data.R` | **Downloads** every Age x Sex x Race selection of the CDC VEHSS AMD indicator from the portal's JSON endpoint (the same data its Export button emits), writes one csv per selection in the portal's export layout to `C:/Work/2026 Spring/Sub RAILS/VEHSS`, then merges them into `VEHSS_AMD_overall.csv`, `VEHSS_AMD_combinations.csv` and `VEHSS_AMD_coverage.csv` (written both there and here; csvs are git-ignored). Cached files are checked by **content**: a hand export whose name disagrees with its content (the portal's export lags its dropdowns) is re-downloaded |
| `VEHSS_data_eye.R` | Multi-phenotype version of `VEHSS_data.R`: downloads the VEHSS reference for **AMD** (modeled, 2019), **glaucoma** (modeled, 2022; the portal has no 40+ selection, so 40+ is derived from the 40-64 / 65-84 / 85+ bands) and **cataract** (Medicare FFS + Advantage diagnosed cataract, 2022; the portal's "Other" race excludes Asian and North American Native, so a comparable "Other" is derived; denominator = Medicare beneficiaries). Writes `VEHSS_<AMD|GLAUCOMA|CATARACT>_{overall,combinations,coverage}.csv` and prints the age / sex / race differences between the three indicators |
| *(all `VEHSS_comparison*.R`)* | Each phenotype script carries a `PHENO_DEF` switch: `"phecodeX"` (default) defines the AoU cases by the exact ICD-9/10 code list of the PhecodeX phecode — AMD `SO_374.51`, glaucoma `SO_375.1`, cataract `SO_371`, child phecodes included, lists embedded from `phecodeX_R_map.csv` + `phecodeX_R_rollup_map.csv` — matching the manuscript's phecode-based phenotyping; `"vehss"` uses the VEHSS-crosswalk prefix lists. The differences between the two definitions are documented in each script |
| `VEHSS_comparison_AMD_twoway_region.R` | `VEHSS_comparison.R` (full AoU cohort, AMD, by region) with only the **model order** changed: the two-way estimators `fun.rails.twoway` / `fun.sub.rails.twoway` (one-way base, forward selection of two-way interactions, LIFO raking) instead of the three-way ones. Outputs `vehss_amd_twoway_*`; compare with the three-way run to see how much the state estimates depend on the model order |
| `VEHSS_comparison_AMD_eyehis_region.R` | `VEHSS_comparison.R` with the AoU sample **restricted to participants with eye-care contact** (ophthalmology / optometry provider, eye care site, or eye-examination CPT / HCPCS code; switches and a minimum number of contact dates) before RAILS calibrates it to the unchanged PUMS 40+ totals — only the non-probability sample shrinks. Because the sample is smaller it uses the two-way estimators (`fun.rails.twoway`, `fun.sub.rails.twoway`: one-way base, selected two-way interactions). Same stages, region stratification and figures; outputs `vehss_amd_eyehis_*`, plus `vehss_amd_eyehis_cohort_restriction.csv` with cohort sizes and unweighted AMD prevalence before / after |
| `VEHSS_comparison_glaucoma.R` | `VEHSS_comparison.R` with the phenotype swapped to **glaucoma** (VEHSS crosswalk category 5 without glaucoma suspects; reference = VEHSS modeled estimate 2022, 40+ derived). Same stages, region stratification, fallback and figures; reads `VEHSS_GLAUCOMA_*.csv`; outputs `vehss_glaucoma_*` |
| `VEHSS_comparison_cataract.R` | `VEHSS_comparison.R` with the phenotype swapped to **cataract** (VEHSS crosswalk category 6 "All Cataracts" incl. pseudophakia / aphakia / congenital, switchable; condition_occurrence + observation searched so Z96.1 counts; reference = Medicare FFS + Advantage diagnosed cataract 2022, Medicare-beneficiary denominator). Reads `VEHSS_CATARACT_*.csv`; outputs `vehss_cataract_*` |
| `VEHSS_comparison_agegroup.R` | Same study with the Subgroup RAILS stratum set to **age group** (40-64 / 65-84 / 85+) instead of region; region stays in the within-band model. Identical stages, fallback and figures, plus a national by-age-band comparison; every output is `vehss_age_`-prefixed so the by-region outputs are kept |
| `VEHSS_comparison.R` | **Self-contained AMD study, adults 40+**, re-running every stage on each execution (set `SKIP_IF_CACHED <- TRUE` only to reuse earlier stage outputs). Reads the two `VEHSS_AMD_*.csv` tables produced by `VEHSS_data.R`, which is run separately: rebuilds the PUMS (by state) and AoU cohorts restricted to age >= 40, defines age-related macular degeneration from ICD-9/10 codes, runs Global RAILS and region-Subgroup RAILS on the 40+ cell tables (falling back to Global RAILS weights in a region whose subgroup fit fails), and compares Subgroup RAILS (with unweighted / Global RAILS as references) to the VEHSS modeled estimates overall and for every Age x Sex x Race combination: state maps with region outlines for the overall, most-populated, high-D and low-E combinations, a D-vs-E scatter of all combinations, plus the overall scatter / dot plot / regional figures. All outputs are `vehss_`-prefixed so nothing in the main pipeline is overwritten |
